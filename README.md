# Shri Ram — Cinematic Introduction (60 s, Blender, built in the cloud)

A 60-second, 24 fps, 2.39:1 opening sequence of Shri Ram moving through an ancient Indian forest.
Everything is generated by code and rendered on GitHub Actions — nothing runs on a local PC.

## Run it
**Actions → Shri Ram Film → Run workflow**
- `quality`: `preview` (1280×536, fast) or `final` (1920×804, high samples, motion blur)
- `shards`: parallel render machines (default 24)
- `render_movie`: untick to only build the scene and render one still per shot

The finished film, the score, per-shot stills and the editable `.blend` project are published as a
**GitHub Release** (and as workflow artifacts).

## Pipeline
| Step | File | What it does |
|---|---|---|
| Assets | `pipeline/fetch_assets.py` | Poly Haven CC0 trees, ferns, roots, rocks, forest-floor/bark textures, HDRI; MPFB human generator + CC0 system assets |
| Environment | `pipeline/environment.py` | Terrain + trail, giant buttress-root trees, scattered vegetation, vines, sun, sky, volumetric haze, dust motes |
| Character | `pipeline/character.py` | MPFB human with mixamo rig; dhoti, uttariya, kamarband, quiver strap derived from the body surface; groomed hair + topknot; tilak; rudraksha mala; armlets; bracers; sandals; carved bow with drawable string; quiver and arrows |
| Animation | `pipeline/animation.py` | Own FK/IK pose solver: walk cycle with planted feet and root step-over, bow grip, drawing an arrow from the quiver, nocking, full draw, let-down; 10 directed shots with camera moves, focus pulls, per-shot key/rim lights, birds |
| Scene | `pipeline/build_scene.py` | Cycles settings, AgX grade, compositor (mist haze, bloom, lift/gamma/gain, vignette, lens dispersion), packs and saves the project |
| Render | `pipeline/render_shard.py` | Renders a slice of frames per machine |
| Score | `pipeline/score.py` | Original synthesised score (tanpura, bansuri, strings, choir, brass, taiko/dhol) + synced sound design and forest ambience |
| Assemble | `pipeline/assemble.sh` | Joins shots, film grain, title card, fades, muxes audio |

## Shot list
1. Establishing — low crane through giant trunks into the light; a distant figure
2. Ground level — roots and ferns; his feet step over a root
3. Low tracking shot behind him between enormous trees
4. Close-up — the hand tightening on the bow
5. Birds burst from the canopy
6. He stops and turns, alert
7. Extreme close-up — the eyes
8. Over the shoulder — draws an arrow from the quiver and nocks it
9. Low orbit — raises the bow and draws to the anchor, sun behind
10. Hero — holds, lets the draw down with restraint, stands tall; crane back reveals the forest; title
